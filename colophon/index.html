/colophon

Notes on how this site is made, hosted, and kept small.

build

site
Mostly static HTML and CSS.
hosting
GitHub Pages with the custom domain raearea.net.
/whoami
Written in Markdown and rendered to committed HTML by a small Node.js script using built-in modules.
client-side JS
Not required by the homepage or /whoami.
fonts
IBM Plex Mono and VT323, self-hosted.

web stuff

markup
Semantic HTML where it is useful; ordinary links and document structure before custom interface behavior.
accessibility
Keyboard-visible focus, skip links, responsive layouts, reduced-motion handling where motion exists, and print styles on newer pages.
analytics
No analytics script is currently included in the site source.
indexing
The homepage currently asks search engines not to index, follow, or archive it.

other doors

  • whoami.md — source text for /whoami
  • hello.txt — an old-fashioned plain-text hello
  • agent-contact.json — machine-readable public agent-contact artifact
  • agent-hello.txt — human-readable context for that experiment
  • source — this site's repository

notes

The site changes when there is a reason for it to change. It does not need a framework, CMS, design system, or build pipeline merely because those things exist.
